# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [1.0.0] - 2026-08-28

### Added
- Initial global Android coding standards (`rules.md`)
- Package naming convention (`com.hotmail.or_dvir.<app_name>`)
- Debug build type suffixes (`.debug` / `-DEBUG`)
- MVI / MVVM architecture guidelines with pragmatic state management
- Lifecycle-aware collection (`collectAsStateWithLifecycle`)
- Recomposition stability (`@Immutable` / `@Stable`)
- Material 3 expressive color & tonal container directives
- Semantic color extensions (`success`, `warning`, `info`)
- Edge-to-edge layout enforcement
- 3-way theme selection with DataStore persistence
- Firebase debug/release project separation
- UI options generation (3-4 archetypes)
- Preview strategy guidelines
- Non-disruptive guardrail (suggest, don't auto-refactor)
- Agent behavior rules (clarify over assume, code over memory, concise language)
- Token/rate-limit optimization directive
- Project-level `AGENTS.md` template
- `.gitignore` for Antigravity internals
- Installed skills: navigation-3, edge-to-edge, adaptive, styles, migrate-xml-views, testing-setup, android-profiler, r8-analyzer, android-intent-security, play-policy-insights, agp-9-upgrade, camerax, play-billing-upgrade, verified-email, appfunctions
